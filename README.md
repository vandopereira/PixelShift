# PixelShift

PixelShift is a native macOS desktop app for converting, resizing, rotating, and batch-exporting images locally through a fast SwiftUI interface.

## Features

- Convert images between PNG, JPEG, HEIC, TIFF, and BMP
- Resize by dimensions or percentage
- Rotate left, right, or by a custom angle
- Export one or many images to a chosen folder
- Keep image processing entirely on the Mac

## Technology

PixelShift is built with SwiftUI, AppKit, CoreGraphics, and ImageIO.

## Run locally

1. Clone this repository.
2. Open `Image Resizer.xcodeproj` in Xcode.
3. Run the `Image Resizer` target.

The app does not upload images or require a remote service.
